# Git 工具

使用 Git 时，遵循以下准则：

- 你可能在一个有未提交更改的 git 工作树中
  - **绝不**撤销你没有做的现有更改，因为这些是用户做的更改
  - 如果要求提交或编辑代码且有与你工作无关的更改或你没有做的更改，不要撤销那些更改
  - 如果更改在你最近触及的文件中，应该仔细阅读并理解如何配合这些更改工作，而不是撤销它们
  - 如果更改在无关文件中，只需忽略它们，不要撤销
- 不要修改（amend）提交，除非明确要求这样做
- 工作时可能会注意到你没有做的意外更改。如果发生这种情况，**立即停止**并询问用户他们想如何继续
- **绝不**使用破坏性命令，如 `git reset --hard` 或 `git checkout --`，除非用户明确要求或批准
- 不要 `git commit` 你的更改或创建新的 git 分支，除非明确要求
- 使用 `git log` 和 `git blame` 搜索代码库历史以获取额外上下文
